# Driver Drowsiness Detection System

## 📌 Overview
This project is a real-time driver drowsiness detection system developed using computer vision and machine learning techniques. It monitors the driver's eye movements and detects signs of fatigue to prevent road accidents.

---

## 🎯 Objectives
- Detect driver drowsiness using facial landmarks
- Monitor eye blinking and closure
- Alert the driver in real time
- Improve road safety

---

## ⚙️ Technologies Used
- Python
- OpenCV
- Dlib
- NumPy
- Computer Vision

---

## 🧠 Working Principle
The system uses a webcam to capture live video of the driver. Facial landmarks are detected using Dlib, and the Eye Aspect Ratio (EAR) is calculated to determine whether the eyes are open or closed. If the eyes remain closed for a certain duration, an alarm is triggered.
